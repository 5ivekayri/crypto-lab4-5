# Мини-шпаргалка — LAB4

**Что сделал:** проверил пример из методички, исправил размер блока, реализовал
шифрование и расшифрование файлов, проверил работу с разными паролями.

| Вопрос | Короткий ответ |
| --- | --- |
| Что такое AES? | Симметричный блочный шифр: один ключ для шифрования и расшифрования. |
| Размер блока? | Всегда 128 бит = 16 байт. |
| Размеры ключа? | 128, 192, 256 бит; соответственно 10, 12, 14 раундов. |
| Что используется здесь? | AES-256, то есть ключ 32 байта и 14 раундов; CBC, PKCS7. |
| Что делает SubBytes? | Заменяет каждый байт по таблице S-box. |
| Что делает ShiftRows? | Циклически сдвигает строки матрицы состояния. |
| Что делает MixColumns? | Перемешивает байты каждого столбца. |
| Что делает AddRoundKey? | XOR состояния с раундовым ключом. |
| Особенность последнего раунда? | В нём нет MixColumns. До первого раунда есть AddRoundKey. |
| Откуда раундовые ключи? | Получаются из основного ключа по расписанию ключей. |
| Пароль равен ключу? | Нет. PBKDF2 получает ключ из пароля и salt. |
| Salt? | Случайная добавка к получению ключа, здесь 32 байта. |
| IV? | Начальное значение для CBC, здесь 16 байт. |
| CBC? | Перед шифрованием блок XOR-ится с предыдущим шифроблоком; первый — с IV. |
| PKCS7? | Дополняет данные до целого числа блоков; даже кратный блоку текст получает дополнительный блок. |
| Base64? | Представление байтов печатными символами, само по себе не шифрует. |
| Что хранится в файле? | Base64 от salt + IV + шифротекста. |
| Почему один текст каждый раз шифруется по-разному? | Генерируются новые salt и IV. |
| Как менял ключ? | Менял пароль, из которого PBKDF2 получает ключ; размер оставался 256 бит. |
| Что при неверном пароле? | Ошибка или неверный текст; CBC без MAC не гарантирует обнаружение подмены. |
| Ошибка методички? | Rijndael с блоком 256 бит — не AES; для AES блок должен быть 128 бит. |

Показать преподавателю из папки `LAB4`:

```sh
dotnet run -- self-test
dotnet run -- demo
dotnet run -- encrypt samples/input.txt encrypted.txt
dotnet run -- decrypt encrypted.txt decrypted.txt
```

В последних двух командах вводится одинаковый пароль. Выходные файлы должны быть
новыми. В `demo` пароли A и B заданы в коде специально для воспроизводимого показа.

Исходный текст восстанавливается с правильным паролем. Salt нужен для получения
ключа, IV — для CBC. Исправил в методичке смешение размера ключа и размера блока».
