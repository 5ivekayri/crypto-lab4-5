Практическая часть
В лабораторной работе показаны способы получить хеш-код введенных пользователем строк и сравнить два хеш-значения, чтобы проверить, совпадают ли они.
Класс System.Security.Cryptography платформы .NET Framework Microsoft позволяет сделать вычисления хеш-значения для введенной строки.
Вычисление хеш-функции.
System.Security.Cryptography позволяет создавать и сравнивать хеш-значения с использованием ресурсов, содержащихся в данном пространстве имен. Поскольку все функции хеширования входного типа Byte[], может потребоваться преобразовать источник в байтовый массив, прежде чем хешировать его. Чтобы создать хеш для строкового значения, выполните следующие действия.
Откройте Microsoft Visual Studio 2005 или 2007.
Создайте новое консольное приложение Visual C#.
Необходимо с помощью ключевого слова using объявить пространства имен System.Security.Cryptography и System.Text.
using System;
using System.Security.Cryptography;
using System.Text;
Объявите переменную типа string для хранения исходных данных и два байтовых массива (неопределенного размера) для хранения исходных байтов и результирующего значения хеша.
string s1SourceData, s2SourceData;
byte[] tmpSource;
byte[] tmpHash;
byte[] tmpNewHash;
Используйте метод GetBytes() , который является методом класса System.Text.ASCIIEncoding для преобразования исходной строки в массив байтов (обязательно в качестве входных данных для функции хеширования).
sSourceData = "MySourceData";tmpSource = ASCIIEncoding.ASCII.GetBytes(sSourceData);
Вычисления хеша MD5 для источника данных осуществляется путем вызова метода ComputeHash экземпляра класса MD5CryptoServiceProvider. Обратите внимание, что для вычисления другого хеш-значения, необходимо создать другой экземпляр класса.
tmpHash = new MD5CryptoServiceProvider().ComputeHash(tmpSource);
Массив байтов, в tmpHash теперь содержит вычисленное значение хеша (128-разрядное значение = 16 байт) для источника данных. Часто бывает полезно отображать или хранить вычисленные значения в виде шестнадцатеричной строки, что выполняет следующий код:
static string ByteArrayToString(byte[] arrInput)
        {
            int i;
            StringBuilder sOutput = new StringBuilder (arrInput.Length);
            for (i = 0; i < arrInput.Length - 1; i++)
            {
                sOutput.Append(arrInput[i].ToString("X2"));
            }
            return sOutput.ToString();
        }
Сохраните и запустите полученный код.
Сравнение двух хеш-значений
В случае, если необходимо сравнить два вычисленных хеш-кода, сделать это не несложно, если они хранятся как шестнадцатеричные строки. Однако, вполне возможно, что они будут в виде байтовых массивов. Следующий код, который является продолжением кода, созданного в предыдущем разделе, и показывает, как сравнить два байтовых массива.
Сразу после создания шестнадцатеричной строки создайте новое значение хеша на основе нового источника данных.
sSourceData = "NotMySourceData";
tmpSource = ASCIIEncoding.ASCII.GetBytes(sSourceData);
byte[] tmpNewHash;
tmpNewHash=new D5CryptoServiceProvider().ComputeHash(tmpSource);
Самый простой способ сравнения двух байтовых массивов является перебор элементов массивов, сравнение каждого отдельного элемента со своим аналогом из второго массива. Если какие-либо элементы отличаются или два массива имеют разный размер, эти два значения не равны.
bool bEqual = false;
            if (tmpNewHash.Length == tmpHash.Length)
            {
                int i = 0;
                while ((i < tmpNewHash.Length) && (tmpNewHash[i] == tmpHash[i]))
                {
                    i += 1;
                }
                if (i == tmpNewHash.Length)
                {
                    bEqual = true;
                }
            }
            if (bEqual)
                Console.WriteLine("The two hash values are the same");
            else
                Console.WriteLine("The two hash values are not the same");
